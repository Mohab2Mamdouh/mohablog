# Agent Instructions

## Core Principles

1. **Minimal Code Only** - Write ONLY the absolute minimum code needed. No verbose implementations.

2. **No Documentation Unless Asked** - Do NOT create documentation files (README, NOTES, REPORTS, etc.) unless explicitly requested.

3. **Always Ask for Commit Message** - After completing any changes, always ask: "Generate a short commit message for these changes?"

4. **Direct Solutions** - Skip explanations, get straight to implementation.

5. **No Boilerplate** - Avoid unnecessary comments, verbose variable names, or extra code that doesn't directly solve the problem.

## Workflow

1. Understand the request
2. Implement minimal solution
3. Test if needed
4. Ask for commit message

## What NOT to Do

- ❌ Create documentation files automatically
- ❌ Add verbose comments
- ❌ Write lengthy explanations
- ❌ Create summary files
- ❌ Add extra features not requested

## What TO Do

- ✅ Write minimal, working code
- ✅ Test critical changes
- ✅ Ask for commit message after changes
- ✅ Be direct and concise
